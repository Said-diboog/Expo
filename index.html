La búsqueda normal se detiene apenas encuentra una coincidencia. Si las canicas son [1, 3, 3, 3, 5], se detendría en el índice 2 (el 3 del medio).

Al hallar A[medio] == x, guardamos posicion = medio y forzamos al algoritmo a seguir hacia la izquierda con derecha = medio - 1.

Glosario Interactivo de Estructuras en C++

Utiliza esta guía para responder las preguntas conceptuales del Dr. Ivar Vargas sobre el funcionamiento interno del lenguaje.

for Bucle Determinado

¿Para qué sirve? Repite un bloque de código un número exacto de veces guiado por una variable contador (ej. int i = 0; i < n; i++).

Uso: Recorrer arreglos de inicio a fin.
while Bucle Condicional

¿Para qué sirve? Repite instrucciones **mientras** una condición lógica sea Verdadera (true). No se sabe cuántas vueltas dará de antemano.

Uso: Búsqueda binaria (reducir rango).
if / else Bifurcación Lógica

¿Para qué sirve? Toma decisiones en el programa. Si la prueba dentro de if(...) da verdadero entra a esa rama; si da falso salta al else.

Uso: Evaluar si $A[i] == x$ o comparar pares.
return Finalizador de Función

¿Para qué sirve? Retorna un valor como resultado y **aborta/detiene inmediatamente** la ejecución de la función actual.

¡Cuidado! Si se coloca dentro de un for en la iteración 0, aborta todo el bucle.
temp Variable Auxiliar

¿Para qué sirve? Sirve de respaldo temporal en memoria para intercambiar dos variables sin sobrescribir ni perder el dato original.

Fórmula: temp = A; A = B; B = temp;
Firma / Orden Parámetros

¿Para qué sirve? Las funciones en C++ son estrictas con el tipo y el orden de los datos que reciben. Intercambiarlos provoca errores de compilación o lecturas inválidas.

Ejemplo: mostrar(A, n) ≠ mostrar(n, A).
